# Отложено

## Независимый выбор LLM при запуске чата — 2026-09-21

Один Agent Profile должен работать с разными LLM-профилями, выбранными в чате.
Промпт, MCP, инструменты, skills и ограничения секретов остаются от Agent Profile;
модель, endpoint, ключ и параметры генерации — от выбранного LLM Profile.
Привязка LLM внутри агента служит значением по умолчанию. Выбор для нового чата
не должен переписывать профиль или менять уже созданные разговоры.

Сейчас патч блокирует несовпадение LLM, чтобы Canvas не потерял настройки агента
при fallback на общие agent_settings. Будущая доработка должна провести явный
LLM override через API запуска, сохранить обе выбранные конфигурации в разговоре
и проверить отсутствие fallback/утечки настроек между профилями. Пока не реализуем.

## Приложение «Исследовательский RAG» для Canvas — 2026-09-21

Рассмотреть отдельную страницу через Apps / Canvas Extensions API: настроить и
связать MCP корпуса, системный промпт, доступные инструменты и независимо выбранный
LLM-профиль; сохранить исследовательскую конфигурацию. Промпт получать именно
существующей специальной командой экспорта из MCP, а не сочинять замену;
показывать полученный текст пользователю.

На странице — начальный запрос и кнопка «Начать исследование». Приложение собирает
конфигурацию Agent, создаёт разговор через Agent Server API и открывает его в
обычном чате Canvas. Настройки фиксируются для разговора; изменения сохранённой
конфигурации не затрагивают старые разговоры или обычные агентские профили.

До реализации проверить доступность штатного экспорта промпта через серверный API
и передачу MCP-конфигурации с серверными учётными данными без раскрытия ключей
в браузере. Уточнить хранение исследовательских конфигураций и необходимость
дополнительной серверной части. Apps поддерживают отдельные страницы и HTTP-запросы,
но сами по себе не расширяют штатный редактор Agent Profiles. Возможность обойтись
без текущих патчей — гипотеза для проверки, не готовое решение. Пока только заметка.
