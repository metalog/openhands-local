# Отложено

## Независимый выбор LLM при запуске чата — 2026-09-21

Один Agent Profile должен работать с разными LLM-профилями, выбранными в чате.
Промпт, MCP, инструменты, skills и ограничения секретов остаются от Agent Profile;
модель, endpoint, ключ и параметры генерации — от выбранного LLM Profile.
Привязка LLM внутри агента служит значением по умолчанию. Выбор для нового чата
не должен переписывать профиль или менять уже созданные разговоры.

Сейчас патч блокирует несовпадение LLM, чтобы Canvas не потерял настройки агента
при fallback на общие agent_settings. Будущая доработка должна провести явный
LLM override через API запуска, сохранить обе выбранные конфигурации в разговоре
и проверить отсутствие fallback/утечки настроек между профилями. Пока не реализуем.
